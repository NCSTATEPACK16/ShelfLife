Art direction · Gemini prompt set

Shelf LifePlanogram

Ten prompts that hand the art direction and the UI/UX to Gemini and get it back as concept art plus a machine-readable spec. Ordered against the surface roadmap, so each one targets the next thing Track B actually builds. Every card copies the full prompt with the shared blocks it needs already inside it.

Read this before generating anything

The palette above is not a suggestion. It is content/design/tokens.json, the single source of colour truth for the store world, the UI, and the landing page — and tools/check-tokens.mjs fails CI on a hardcoded hex. So the prompts never ask for a palette. They ask for proposed changes to named tokens, and a long list of proposals means the brief was ignored.

The projection is orthogonal 3/4 top-down on a 32px grid, per ADR 0004 — not the isometric spec still sitting in PLAN.md §9.1, which that ADR supersedes. Image models default to isometric diamonds for anything that looks like a management game, so every prompt says so twice.

And the art is text. Sprites are palette-index character grids in tools/art/sprites/*.py compiled to PNG by npm run art:build (ADR 0006). Gemini's pictures are concept and spec, never shippable frames — which is exactly why every prompt ends in a HANDOFF block you can paste back to Claude Code.

How to run the set

  1. 1One fresh chat per prompt. Mixing the HUD prompt and the rival-logo prompt in one thread produces mush.
  2. 2Run 01 first and keep the winner. It is a form-language board, not a scene, and everything downstream inherits its material ramps, light direction, and detail budget.
  3. 3Then 02, and keep that too. It turns known US grocery-format archetypes — no photos needed — into the fixture vocabulary, stated explicitly in a 16-bit SNES style. From 03 on, attach both as references — 01 carries the objects, 02 carries the world.
  4. 4Attach the folder named on each card. Photos in docs/art-direction/reference/. Every prompt already contains an IF I ATTACHED IMAGES clause telling the model what to take from them and what to ignore.
  5. 5Expect garbled lettering. Judge UI output on layout, weight, and placement only. The real text lives in HTML, and the real sprite text is a bitmap font.
  6. 6Iterate on the HANDOFF, not the picture. If the art is 80% right, the fix is usually one value in the spec. Say keep everything, move the speed control to the left edge rather than re-rolling a composition you liked.

Every prompt is assembled from a few of these plus its own text. A card only carries the blocks it needs — the cast sheet never sends the KPI benchmark rule, and the advisor panel never sends the fixture rotation budget. The copy button does the assembly, so these are here to read and tune once.

Foundation

Run these two first and keep both results. Everything after them is a variation on what they establish — 01 defines the objects, 02 defines the world they sit in.

The world

The store, the tells, and the cast. This is the art that carries the simulation: shoppers are the telemetry channel, so their legibility is a mechanic, not a finish.

The interface

All three are designed at 390×844 first and expanded to desktop second. A panel that only works at regular width fails review, so a prompt that returns only a desktop layout has failed too.

Identity & framing

The twelve rival chains and the art around the game. Prompt 09 carries the trademark guardrails — its output goes into docs/legal/parody-review.md before any of it is implemented.

What comes back: images for you, and a fenced HANDOFF block for me. The HANDOFF is JSON on purpose — token deltas land in content/design/tokens.json, asset entries in content/asset-manifest.json, palette maps in the manifest's palettes block, and sprite designs become character grids in tools/art/sprites/. Never hand-edit a PNG.

Two things that are not optional: a rival gets logged in the parody review before it is implemented, and a third-party asset gets recorded in ATTRIBUTION.md when it is added. And if an art change moves a golden hash, that is a boundary violation to fix — never a re-baseline.

These prompts are downstream of PLAN.md, CLAUDE.md, ADRs 0004–0007, and docs/design/gentle-surface.md. If they disagree, those win.
